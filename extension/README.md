# NoWorryCV 投递助手

这是对 `JobAutoAgent/extension` 初版表单引擎的整合版本，代码随 NoWorryCV 一起维护。Chrome 116+，Manifest V3，使用常驻侧栏。无需构建或前端依赖。

## 安装与使用

1. 在仓库根目录启动服务：`python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000`。先安装 `pip install -e '.[dev]'`，并在 `.env` 中配置模型。
2. 打开 `http://127.0.0.1:8000/app/`，上传简历，确认基础资料及事实，并明确同意保存基础档案。
3. 打开 `chrome://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选中本仓库的 `extension` 目录。
4. 点击插件图标打开侧栏，点击「读取网页已保存档案」。服务地址必须与网页使用的地址一致（`localhost` 和 `127.0.0.1` 是两个不同来源）。首次连接时保持 NoWorryCV 网页打开。
5. 在岗位详情页点击「识别当前页面」，检查公司、职位和岗位要求。如果申请表在另一个页面，进入该页面后点击「沿用上次识别岗位」。也可以直接粘贴 JD。
6. 助手默认在识别到岗位要求及申请表时自动生成微调简历，可关闭该开关并手动点击生成。插件会复用已确认的基础档案，不重新解析简历；通过真实模型分析 JD 和改写，执行真实性审查，跳过复习与面试准备文档。生成速度取决于模型与资料长度，不保证瞬时完成。
7. 检查微调简历及风险提醒。需要修改时点击「在 NoWorryCV 中编辑此版本」，保存后返回原投递页，点击「重新检测并准备填写预览」。已确认快照保持固定，需要修改时创建新投递版本。
8. 如果页面需要多组经历，勾选「自动新增…」后准备预览。引擎只点击识别到的新增经历按钮，并重新检测表单；没有找到新增按钮时需要手动展开。
9. 编辑或禁用各字段，选择正确的简历附件字段与 PDF/DOCX 格式。确认保存同意后，点击「确认简历、保存并填写」。页面字段或值变化、简历版本变化都会要求重新检查。
10. 查看填写结果，补齐未填写项，并由用户手动提交申请。插件不把「已填写」当作「已投递」。附件控件不兼容时下载同一份已确认简历后手动上传。

## 保存与恢复

确认前的岗位记录与预览按生成任务期限自动过期，只有用户明确确认并同意保存的投递快照长期保留。

生成任务沿用匿名任务的过期机制；投递快照独立保存在 `.dist/applications.sqlite3`（可用 `APPLICATION_STORE_PATH` 修改），由基础档案令牌授权访问。确认操作绑定被预览版本的 SHA-256 摘要，并保存 JD、页面地址、档案版本、简历、事实来源及填写结果。已确认的快照不受生成任务过期、草稿后续编辑或基础档案更新影响。记录保留至用户主动删除；删除基础档案也会删除其投递记录。对应匿名生成任务仍沿用原有过期和删除策略。

侧栏关闭后后端继续生成；再次打开时可恢复原页面任务，或从记录列表查看。后端先保存确认快照，再改写页面；填写结果上传失败时，插件保存待同步报告，点击记录的「查看 / 恢复」可以重试同步。浏览器本地只保存连接凭据、任务索引、最近一次识别的 JD 和待同步报告，不保存示例候选人或模型密钥。

## 当前支持范围

- 优先解析 JobPosting JSON-LD，其次从岗位正文提取；页面不含 JD 时提供手动输入。识别结果始终可检查与修改。
- 复用初版规则映射与置信度，支持当前顶层页面的标准 input、textarea、select，以及动态新增教育、工作和项目经历。未知问题可在预览中手工填写并启用；缺失资料不会自动编造。
- 通过事实来源和唯一的经历标识关联重排后的经历，匹配不唯一时不自动填写公司、角色或日期。
- 原生文件字段可接收已确认的 PDF/DOCX；自定义上传器、跨域 iframe、Shadow DOM、复杂下拉、日期选择器、验证码、勾选框、单选框和多步流程仍需手动处理或后续站点适配。文件被浏览器控件接收不等于站点服务器上传成功，需要用户检查。
- 后端请求来自扩展侧栏，页面脚本不持有基础档案令牌。连接当前限定本机 HTTP 服务；公开服务的账户登录、租户与站点适配属于后续工作。
- 撤销恢复本页最近一次被插件修改的标准文本字段，附件在招聘页面手动移除；撤销不会删除已确认的快照或重写历史填写报告。

## 验证

```sh
python -m pytest -q
node --test extension/tests/form_engine.test.cjs
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/extension/tests/demo_application.html` 可以手动验证岗位识别、新增项目、基础字段、改写描述、未知问题和简历附件。后端测试使用 stub 模型验证流程，不调用真实模型。

Chrome API 依据：[扩展跨域请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[侧栏 API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[扩展存储](https://developer.chrome.com/docs/extensions/reference/api/storage)。
